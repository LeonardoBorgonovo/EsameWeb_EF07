# EsameWeb_EF07
Esame finale UF07-ProgrammazioneWeb


## Esercizio 1
### Come utilizare

1. Apri il file `index.html` nel tuo browser web.
2. Troverai un campo di input in cui puoi inserire le task, poi con il tasto aggiungi vengono aggiunte al LocalStorage.
3. Ci sono dei filtri di ricerca, ceh cercano in base allo stato di avanzamento della task, oppure una barra di ricerca per cercare il nome della task-
4. C'è anche l'opzione per eliminare il task, oppure modidicarlo.


## Esercizio 2
### Come utilizzare

1. Apri il file `index.html` nel tuo browser web.
2. Vedrai il cronometro digitale con 4 pulsanti: Avvia, Ferma, Azzera e Giro.


## Esercizio 3
### Come Utilizzare

1.  Apri il file `index.html` nel tuo browser web.
2.  Troverai due campi di input: "Latitudine" e "Longitudine". Inserisci le coordinate geografiche per la località di cui vuoi visualizzare il meteo attuale. Puoi trovare queste coordinate utilizzando servizi di mappe online.
3.  Dopo aver inserito la latitudine e la longitudine, fai clic sul pulsante "Ottieni Meteo".
4.  L'applicazione chiamerà l'API di Open-Meteo e visualizzerà le informazioni meteo attuali (temperatura, vento, condizione del cielo, ecc.) all'interno di una card sulla pagina.
